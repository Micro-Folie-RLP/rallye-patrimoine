# Rallye Patrimoine - Roquefort-les-Pins

Application web interactive créée pour les Journées Européennes du Patrimoine.

## Description

Les participants démarrent le parcours en scannant un QR Code.

Ils découvrent ensuite :

- des informations historiques sur les lieux emblématiques de la commune ;
- des défis à réaliser ;
- des indices pour trouver l'étape suivante.

L'application est optimisée pour une utilisation sur smartphone.
